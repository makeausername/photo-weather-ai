# 暮光蓝界面更新与验证记录

日期：2026-10-01。

本次更新改善摄影天气页面的阅读层级、专业数据呈现和响应式布局。天气计算与数据服务商调用规则没有调整。

## 界面变化

- 日间使用暖白背景 `#F7F7F2`、深蓝主色 `#263D55` 与蓝色数据色 `#527DA8`。判断结论集中在深蓝摘要区，状态标签保留各自的风险含义。
- 增加可记忆的夜间阅读模式。浏览器存储不可用时仍能切换；首次加载读取偏好，避免整个页面先显示日间主题。
- 统一正文、说明、数字与标题层级，弱化重复边框、阴影和卡片嵌套。首页、云海、霞光和星空入口及结果页共用视觉规范。
- 日期作为辅助信息，窗口与结果作为主信息。星空摘要的日期和时间采用中性色，仅建议状态使用强调色。
- 页面最大宽度统一为 1440px。表格横向滚动限于表格区域，输入字号至少 16px，主要导航及筛选按钮高度为 44px。
- 专业数据增加“全部指标 / 云层 / 温湿与风 / 降水与能见度”分组。指标分组不会改变小时筛选，也不会重新显示业务配置隐藏的列。
- 日期、时间两列固定；数字右对齐并使用等宽数字；单位放在表头。降水量 mm 与降水概率 % 分列，云量用同一蓝色的深浅表示数值大小。
- 缺失数值显示 `—`，实际零值显示 `0`，小于显示精度的非零值显示上界或下界，避免微量降水被误读为零。降水保留最多两位小数，温度、风速、能见度最多一位小数，百分比最多零位小数。
- 数据口径、覆盖明细折叠展示；覆盖不足、缺失与口径冲突的提示继续直接可见。
- 逐小时图表拆为共用时间轴的云量、降水、气温与露点三条轨道。降水量和概率分别标明左右轴；缺失数据保持断线，键盘操作可同步查看三图提示。

浏览器结果页检查通过本地回放工具加载实际页面组件与保存的 API 响应，工具中的 Next.js 适配代码仅用于测试，不随产品发布。公共页面检查使用本地生产构建。证据保存在本机 `.codex-live-audit/ui-20261001/`，不提交 API 存档或临时测试工具。

这些结果验证前端展示与已保存响应的一致性，不代表重新调用气象服务商验证实时天气，也不代表已完成服务器部署或所有实体设备测试。登录、注册、支付和管理写入流程没有在本次浏览器检查中提交。移动布局静态扫描的最小宽度等启发式提醒仍需结合实际滚动区域判断，本次以浏览器布局和交互结果为依据。

## 服务器更新

使用既有部署账户，在服务器项目目录执行：

```bash
cd /opt/photo-weather-ai
git status --short
DEPLOY_BRANCH=main bash scripts/update.sh
git rev-parse --short HEAD
docker compose --env-file .env.production -f docker-compose.prod.yml ps
curl --fail --show-error https://zhuguangweather.com/api/health
```

更新脚本会拉取主分支、构建生产镜像并启动服务。如果工作区存在未提交文件，先核对并保留这些修改，再运行更新；脚本会拒绝混合源码部署。核对服务器提交号与本次合并后的主分支提交一致，并确认容器没有 `unhealthy`、`exited` 或持续重启状态。

更新成功后浏览器强制刷新，在至少一个山地机位和一个城市机位分别检查首页、云海、霞光与星空结果。重点检查夜间模式、手机菜单、三轨图表、指标分组、固定日期/时间列及降水量/概率的独立显示；缺失与冲突提示应保持可见。新版本不需要增加环境变量或下载外部字体。
